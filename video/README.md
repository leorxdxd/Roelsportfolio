# Portfolio media: showreel, project images, hero portrait

A 35-second, 1080p promo video built entirely in code with [Remotion](https://www.remotion.dev): React components rendered to MP4.
Everything in it (UI, cursor, transitions, music, sound effects) is generated, so it contains **no real client data**.

```bash
cd video
npm install
npm run studio   # live preview + timeline in the browser (edit code, see changes instantly)
npm run render   # → out/showreel.mp4
npm run site     # render + copy showreel.mp4 and a poster frame into the website (public/assets/showreel/)
```

The poster frame is set by `POSTER_FRAME` in `scripts/publish-to-site.mjs`.

## Story (8 scenes, cuts land on the beat at 120 BPM)

| # | Scene | File |
| - | --- | --- |
| 1 | "Lyrics" typed in a notes app: the client's problem | `src/scenes/S1Notes.tsx` |
| 2 | AI search finds Roel (answer streams in, cursor clicks the result) | `S2Search.tsx` |
| 3 | "My Day" story with your photos | `S3Story.tsx` |
| 4 | Video editor: cursor drags project clips onto the timeline, exports | `S4Editor.tsx` |
| 5 | Live helpdesk demo: new ticket → assign → resolved | `S5Helpdesk.tsx` |
| 6 | Photo library: cursor checks every photo, publishes | `S6Photos.tsx` |
| 7 | Reels feed of your projects | `S7Reels.tsx` |
| 8 | Outro: your website + "Let's build yours." | `S8Outro.tsx` |

Timing lives in `src/timeline.json` (cut points in frames, 30 fps). Transitions are in `src/Showreel.tsx`.

## Personalise

- **Name, email, site URL:** `src/config.ts`
- **Your photos:** put them in `public/photos/` (e.g. `photo-2.jpg`, `photo-3.jpg`) and list them in `photos` in
  `src/config.ts`. They're used in the story, search result, photo grid, reels and outro.
  Use photos where you're the only identifiable person, with no school logos, IDs or watermarks.
- **Music:** the default track is an original beat generated by `scripts/make-audio.mjs` (no copyright).
  To use a different song, download a **royalty-free** track (e.g. Pixabay Music, YouTube Audio Library,
  Uppbeat with credit) and save it as `public/music.mp3`. It's picked up automatically. Around 120 BPM keeps the cuts on the beat.
  Don't use commercial songs (e.g. chart hits). They get muted or taken down and aren't licensed for business use.

## Project images (screenshots, thumbnails, posters)

The website's project images are also drawn here, with sample data, in `src/screens/`
(`helpdesk.tsx`, `checker.tsx`, `miromail.tsx`, shared UI in `kit.tsx`, code editor in `code.tsx`).
`src/screens/index.tsx` lists every image; the id `"<project-slug>--<file>"` is the output path.

```bash
npm run images                # render all → ../public/assets/projects/<slug>/<file>.webp
npm run images -- miromail    # only ids containing "miromail"
```

Open `npm run studio` and look in the **Website-images** folder to preview and tweak them live.

## Hero portrait (3D)

```bash
npm run portrait -- path/to/photo.jpg                     # cut-out + depth map → ../public/assets/portrait/
npm run portrait -- path/to/photo.jpg --crop-bottom 0.15  # cut 15% off the bottom first
npm run portrait -- path/to/photo.jpg --smooth 2          # smoother cut-out edge (for small or compressed photos)
```

`scripts/portrait.mjs` uses MODNet (cut-out) and Depth Anything V2 small (depth) through transformers.js.
They download once and run locally. Use a chest-up photo on a plain background, at least 1000 px tall.
